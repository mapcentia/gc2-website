#  Constraints

A constraint is a rule the database enforces on a [table's](./tables.mdx) rows: a primary key identifies each row uniquely, a unique constraint prevents duplicates, a foreign key keeps a reference pointing at an existing row in another table, and a check constraint validates values against an expression. The Constraint API adds, inspects and drops these on GC2 (Geo Compute Cloud) tables without writing DDL, and constraints can also be declared inline when the table is created. A primary key matters in particular for the [Feature API](../features.mdx) and WFS-T editing, which address rows by their key.

Data types are a way to limit the kind of data that can be stored in a table. For many applications, however, the constraint they provide is too coarse. For example, a column containing a product price should probably only accept positive values. But there is no standard data type that accepts only positive numbers. Another issue is that you might want to constrain column data with respect to other columns or rows. For example, in a table containing product information, there should be only one row for each product number.

## Add constraint

A constraint can be of either type primary|unique|foreign|check.

<Tabs>
    <TabItem value="webapp" label="Web App">
        ![Add constraint in the GC2 Web App](/img/screenshots/webapp-placeholder.svg)
    </TabItem>
    <TabItem value="http" label="HTTP">

        ```http title="Create a unique constraint on one column"
        POST https://api.gc2.io/api/v4/schemas/rockhall/tables/inductees/constraints HTTP/1.1
        Content-Type: application/json
        Authorization: Bearer abc123

        {
            "name": "inductees-id-primary",
            "constraint": "primary",
            "columns": ["id"]
        }
        ```

    </TabItem>
    <TabItem value="cli" label="CLI">

        ```bash
        gc2 constraint add "rockhall" "inductees" "id" unique "inductees-id-primary"
        ```

    </TabItem>
</Tabs>

## Get constraint

You can either get a single constraint or a collection of constraints.

<Tabs>
    <TabItem value="webapp" label="Web App">
        ![View constraints in the GC2 Web App](/img/screenshots/webapp-placeholder.svg)
    </TabItem>
    <TabItem value="http" label="HTTP" default>

        ```http title="All constraints for a table"
        GET https://api.gc2.io/api/v4/schemas/rockhall/tables/inductees/constraints HTTP/1.1
        Accept: application/json; charset=utf-8
        Authorization: Bearer abc123
        ```

        ```http title="Specific constraints by name"
        GET https://api.gc2.io/api/v4/schemas/rockhall/tables/inductees/constraints/inductees-id-primary  HTTP/1.1
        Accept: application/json; charset=utf-8
        Authorization: Bearer abc123
        ```

    </TabItem>
    <TabItem value="cli" label="CLI">

        ```bash
        gc2 constraint get "rockhall" "inductees" "inductees-id-primary"
        ```

    </TabItem>
</Tabs>

An index object looks like this.

```json
{
  "name": "inductees-id-primary",
  "constraint": "unique",
  "columns": ["id"]
}
```

## Delete constraint

<Tabs>
    <TabItem value="webapp" label="Web App">
        ![Delete constraint in the GC2 Web App](/img/screenshots/webapp-placeholder.svg)
    </TabItem>
    <TabItem value="http" label="HTTP" default>

        ```http title="Delete constraint by name"
        DELETE https://api.gc2.io/api/v4/schemas/rockhall/tables/inductees/constraints/inductees-id-primary HTTP/1.1
        ```

    </TabItem>
    <TabItem value="cli" label="CLI">

        ```bash title="Delete constraint by name"
        gc2 constraint drop "rockhall" "inductees" "inductees-id-primary"
        ```

    </TabItem>
</Tabs>
