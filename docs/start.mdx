# Getting started

Choose your deployment model first:

- Managed GC2 Cloud: [Sign up and create a backend](/console)
- Self-hosted with Docker: [Open source and self-hosting guide](./opensource)

Then pick whichever interface suits you — **Web App**, **CLI**, or **API**. All three give you access to the full platform.

## Web App

The GC2 Web App is the fastest way to get started. After creating a backend, open the [console](/console) and you can visually manage schemas, tables, columns, users, clients, and more — no code required.

## Use the CLI

Start by logging in to your backend:
```bash
gc2 login
```

Create a new schema for your tables:
```bash
gc2 schema add "rollhall"
```

Create a new table in the schema:
```bash
gc2 table add "rollhall" "inductees"
```

Add columns in your table:
```bash
gc2 column add "rollhall" "inductees" "id" int
gc2 column add "rollhall" "inductees" "name" varchar
```

Then add a primary key to your `id` column:
```bash
gc2 constraint add "rollhall" "inductees" "id" primary
```

Now your table is ready for data inserts:
```bash
echo "INSERT into rollhall.inductees values(1, ‘Guns n’’ Roses’)" | gc2 sql
```

Run queries on your table:
```bash
echo "select * from rollhall.inductees" | gc2 sql
```
