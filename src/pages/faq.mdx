# Frequently asked questions

Welcome! This page answers common questions about GC2 and points you to the right docs to go deeper.

<details>
  <summary>What is GC2?</summary>
  <div>
    GC2 (Geo Compute Cloud) is a geospatial Backend as a Service (BaaS) and infrastructure platform built on PostgreSQL and PostGIS. Import spatial data, query it with spatial SQL or GraphQL, and connect maps and GIS tools through realtime APIs and OGC WMS/WFS services. Use managed GC2 Cloud or self-host with Docker, with authentication and developer tooling included.
  </div>
</details>

<details>
  <summary>How do I get started?</summary>
  <div>
    1) Choose deployment model:
    <br/>- Managed cloud on gc2.io: <a href="/console">/console</a>
    <br/>- Self-host with Docker: <a href="/docs/opensource">/docs/opensource</a>
    <br/>2) Follow Getting started to model your first schema and table: <a href="/docs/start">/docs/start</a>
  </div>
</details>

<details>
  <summary>Should I use GC2 Cloud or self-host?</summary>
  <div>
    Choose GC2 Cloud if you want the fastest path to production and managed operations. Choose self-hosting if you need infrastructure control, custom networking, or strict compliance constraints.
    Start cloud here: <a href="/console">/console</a> and self-host here: <a href="/docs/opensource">/docs/opensource</a>.
  </div>
</details>

<details>
  <summary>How do I model my data?</summary>
  <div>
    Use the CLI to define schemas, tables, columns, and constraints. For example:
    <pre><code>gc2 schema add "app"
gc2 table add "app" "users"
gc2 column add "app" "users" "id" int
gc2 constraint add "app" "users" "id" primary</code></pre>
    See the full walkthrough: <a href="/docs/start">/docs/start</a>
  </div>
</details>

<details>
  <summary>How do I read and write data from my app?</summary>
  <div>
    Use the official SDKs to connect from web or server code: <a href="/docs/sdk">/docs/sdk</a>. You can also issue SQL via the CLI during development.
  </div>
</details>

<details>
  <summary>Does GC2 support realtime updates?</summary>
  <div>
    Yes. Subscribe to data changes to keep web maps, field data and spatial dashboards up to date. Learn more: <a href="/docs/realtime">/docs/realtime</a>
  </div>
</details>

<details>
  <summary>How does authentication work?</summary>
  <div>
    GC2 supports OAuth so you can authenticate users and integrate identity providers. Overview: <a href="/docs/oauth">/docs/oauth</a>
  </div>
</details>

<details>
  <summary>Can I store and serve files?</summary>
  <div>
    Yes. Use Objects to store and serve files alongside your data. Docs: <a href="/docs/objects">/docs/objects</a>
  </div>
</details>

<details>
  <summary>Which platforms and clients are supported?</summary>
  <div>
    See the SDKs overview and available clients here: <a href="/docs/sdk">/docs/sdk</a> and <a href="/docs/clients">/docs/clients</a>
  </div>
</details>

<details>
  <summary>Is GC2 open source or can I contribute?</summary>
  <div>
    GC2 focuses on open, developer‑first tooling and familiar SQL workflows. Learn more on the Open source page: <a href="/docs/opensource">/docs/opensource</a>
  </div>
</details>

<details>
  <summary>How is GC2 different from other BaaS platforms?</summary>
  <div>
    GC2 lets you model data explicitly (schemas, tables, columns) and query with standard SQL, adds realtime where you need it, and provides OAuth and file storage out of the box. Check the Intro for a quick overview: <a href="/docs/intro">/docs/intro</a>
  </div>
</details>

<details>
  <summary>Can I migrate in or out of GC2?</summary>
  <div>
    Your data model is defined with familiar SQL concepts, and you can interact via SQL and SDKs. This makes it straightforward to import seed data during setup and to export data later using the CLI and SQL queries.
  </div>
</details>

<details>
  <summary>Are there limits, quotas, or pricing tiers?</summary>
  <div>
      Right now we are in beta and there are no pricing tiers. Limits are:
      - 10 tables
      - 10 Sub-users
  </div>
</details>

  </div>
</details>
